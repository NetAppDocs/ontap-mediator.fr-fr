= Téléchargez le package d'installation d'ONTAP Mediator
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Téléchargez le package d'installation de ONTAP Mediator et installez-le.

.Étapes
. Téléchargez le package d'installation d'ONTAP Mediator depuis la page de téléchargement d'ONTAP Mediator.
+
https://mysupport.netapp.com/site/products/all/details/ontap-mediator/downloads-tab["Page de téléchargement d'ONTAP Mediator"^]

. Placez le package d'installation de Mediator dans le répertoire de travail actuel :
+
[source, cli]
----
ls ontap-mediator-1.13.0.tgz
----
+
....
ontap-mediator-1.13.0.tgz
....
+

NOTE: Pour les versions 1.4 et antérieures d'ONTAP Mediator, le programme d'installation est nommé `ontap-mediator`.

+
Si votre système ne dispose pas d'accès à Internet, assurez-vous que le programme d'installation puisse accéder aux paquets requis.

. Déplacez le package d'installation de Mediator vers le répertoire d'installation si nécessaire.
. Décompressez le package d'installation :
+
[source, cli]
----
tar xvfz ontap-mediator-1.13.0.tgz
----
+
....
ontap-mediator-1.13.0/
ontap-mediator-1.13.0/csc-prod-ONTAP-Mediator.pem
ontap-mediator-1.13.0/csc-prod-chain-ONTAP-Mediator.pem
ontap-mediator-1.13.0/tsa-prod-ONTAP-Mediator.pem
ontap-mediator-1.13.0/tsa-prod-chain-ONTAP-Mediator.pem
ontap-mediator-1.13.0/ONTAP-Mediator-production.pub
ontap-mediator-1.13.0/ontap-mediator-1.13.0
ontap-mediator-1.13.0/ontap-mediator-1.13.0.sig.tsr
ontap-mediator-1.13.0/ontap-mediator-1.13.0.tsr
ontap-mediator-1.13.0/ontap-mediator-1.13.0.sig
....
