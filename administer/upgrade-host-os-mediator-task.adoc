= Mettez à niveau le système d'exploitation hôte et réinstallez ou mettez à niveau ONTAP Mediator
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Pour mettre à niveau le système d'exploitation hôte pour ONTAP Mediator avec SCST installé vers une version ultérieure, vous devez désinstaller ONTAP Mediator. Après la mise à niveau du système d'exploitation, vous pouvez réinstaller votre version actuelle de ONTAP Mediator ou effectuer une mise à niveau vers une version plus récente.

.À propos de cette tâche
* Cette tâche s'applique aux versions d'ONTAP Mediator avec SCST installé. Si vous avez installé ONTAP Mediator 1.12 ou une version ultérieure avec prise en charge de HTTPS uniquement, le package SCST n'est pas installé et vous pouvez mettre à niveau le système d'exploitation hôte sans affecter ONTAP Mediator. Consultez la documentation du fournisseur du système d'exploitation hôte pour obtenir les instructions de mise à niveau.
* Si vous devez uniquement mettre à jour le noyau du système d'exploitation hôte vers une version prise en charge sans passer à une nouvelle version du système d'exploitation, consultez plutôt link:host-maintenance-task.html["Maintenir le système d'exploitation hôte pour ONTAP Mediator"].
* Avant de mettre à niveau le système d’exploitation hôte d’ONTAP Mediator avec l’outil leapp-upgrade, link:uninstall-mediator-task.html["désinstaller ONTAP Mediator"]. L’outil vérifie la présence de nouvelles versions RPM dans les dépôts enregistrés.
* Le programme d'installation d'ONTAP Mediator installe un fichier .rpm, que l'outil leapp-upgrade inclut dans la recherche. Comme le programme d'installation décompresse le fichier au lieu de le télécharger depuis un dépôt enregistré, l'outil ne peut pas trouver de mise à niveau. Vous devez utiliser l'outil leapp-upgrade pour désinstaller le package.


.Étapes
. Sauvegardez les fichiers journaux :
+
....
[rootmediator-host ~]# tar -czf ontap_mediator_file_backup.tgz -C /opt/netapp/lib/ontap_mediator ./log ./ontap_mediator/server_config/ontap_mediator.user_config.yaml
[rootmediator-host ~]# tar -tf ontap_mediator_file_backup.tgz
./log/
./log/ontap_mediator.log
./log/scstadmin.log
./log/ontap_mediator_stdout.log
./log/ontap_mediator_requests.log
./log/install_20230419134611.log
./log/scst.log
./log/ontap_mediator_syslog.log
./ontap_mediator/server_config/ontap_mediator.user_config.yaml
[rootmediator-host ~]#
....
. Effectuez la mise à niveau avec l'outil leapp-upgrade :
+
....
[rootmediator-host ~]# leapp preupgrade --target 9.8
  ..<snip upgrade checks>..
  ..<fix issues found>..
[rootmediator-host ~]# leapp upgrade --target 9.8
  ..<snip upgrade>..
[rootmediator-host ~]# cat /etc/os-release | head -2
NAME="Red Hat Enterprise Linux"
VERSION="8.4 (Ootpa)"
[rootmediator-host ~]#
....
. Réinstaller ONTAP Mediator:
+

NOTE: Effectuez les étapes restantes immédiatement après la réinstallation de ONTAP Mediator afin d'éviter toute perte de fichiers journaux.

+
....
[rootmediator-host ~]# ontap-mediator-1.12.1/ontap-mediator-1.12.1

ONTAP Mediator: Self Extracting Installer

  ..<snip installation>..
[rootmediator-host ~]#
....
. Arrêtez ontap_mediator:
+
....
[rootmediator-host ~]# systemctl stop ontap_mediator
[rootmediator-host ~]#
....
. Remplacez les fichiers journaux :
+
....
[rootmediator-host ~]# tar -xf ontap_mediator_file_backup.tgz -C /opt/netapp/lib/ontap_mediator
[rootmediator-host ~]#
....
. Démarrer ontap_mediator:
+
....
[rootmediator-host ~]# systemctl start ontap_mediator
[rootmediator-host ~]#
....
. Reconnectez tous les clusters ONTAP à ONTAP Mediator mis à niveau :
