= Fournissez un accès au référentiel pour l’installation de ONTAP Mediator
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous devez autoriser l'accès aux référentiels afin qu'ONTAP Mediator puisse accéder aux packages requis pendant le processus d'installation.

.Étapes
. Déterminez les référentiels auxquels il faut accéder, comme indiqué dans le tableau suivant :
+

|===


| Si votre système d'exploitation est... | Vous devez autoriser l'accès à ces dépôts...

** ol-10-for-x86_64-appstream-rpms




 a| 
Oracle Linux 9.x
 a| 
** ol-9-for-x86_64-baseos-rpms
** ol-9-for-x86_64-appstream-rpms




 a| 
RHEL 10.x
 a| 
** rhel-10-for-x86_64-baseos-rpms
** rhel-10-for-x86_64-appstream-rpms




 a| 
RHEL 9.x
 a| 
** rhel-9-for-x86_64-baseos-rpms
** rhel-9-for-x86_64-appstream-rpms




 a| 
RHEL 8.x
 a| 
** rhel-8-for-x86_64-baseos-rpms
** rhel-8-for-x86_64-appstream-rpms




 a|

** rhel-7-server-optional-rpms




 a|

. Utilisez l'une des procédures suivantes pour autoriser l'accès aux référentiels répertoriés ci-dessus afin qu'ONTAP Mediator puisse accéder aux paquets requis pendant le processus d'installation.
+

NOTE: Si ONTAP Mediator dépend de modules Python présents dans les dépôts « extras » et « optional », il pourrait avoir besoin d’accéder aux `rhel-X-for-x86_64-extras-rpms` et `rhel-X-for-x86_64-optional-rpms` fichiers.

+
.Procédure pour le système d'exploitation Oracle Linux 10.x
[%collapsible]
====
Utilisez cette procédure si votre système d'exploitation est *Oracle Linux 10.x* pour activer l'accès aux référentiels :

.Étapes
.. Abonnez-vous au dépôt requis :
+
[source, cli]
----
subscription-manager repos --enable ol-10-for-x86_64-baseos-rpms
----
+
[source, cli]
----
subscription-manager repos --enable ol-10-for-x86_64-appstream-rpms
----
+
L'exemple suivant illustre l'exécution de cette commande :

+
[listing]
----
[root@localhost ~]# subscription-manager repos --enable ol-10-for-x86_64-baseos-rpms
Repository 'ol-10-for-x86_64-baseos-rpms' is enabled for this system.
[root@localhost ~]# subscription-manager repos --enable ol-10-for-x86_64-appstream-rpms
Repository 'ol-10-for-x86_64-appstream-rpms' is enabled for this system.
----
.. Exécutez la commande suivante pour répertorier les dépôts activés :
+
[source, cli]
----
yum repolist
----
+
Les dépôts auxquels vous venez de vous abonner devraient apparaître dans la liste.

.Procédure pour le système d'exploitation CentOS 7.x
[%collapsible]
====
Utilisez cette procédure si votre système d'exploitation est *CentOS 7.x* afin d'activer l'accès aux dépôts :


NOTE: Les exemples suivants présentent un dépôt pour CentOS 7.6 et peuvent ne pas fonctionner avec d'autres versions de CentOS. Utilisez le dépôt de base correspondant à votre version de CentOS.

.Étapes
.. Ajoutez le dépôt C7.6.1810 - Base. Le dépôt vault C7.6.1810 - Base contient le paquet « kernel-devel » nécessaire à ONTAP Mediator.
.. Ajoutez les lignes suivantes à /etc/yum.repos.d/CentOS-Vault.repo.
+
[source, cli]
----
[C7.6.1810-base]
name=CentOS-7.6.1810 - Base
baseurl=http://vault.centos.org/7.6.1810/os/$basearch/
gpgcheck=1
gpgkey=file:///etc/pki/rpm-gpg/RPM-GPG-KEY-CentOS-7
enabled=1
----
.. Exécutez la commande suivante pour répertorier les dépôts activés :


[source, cli]
----
yum repolist
----
L'exemple suivant illustre l'exécution de cette commande. Le dépôt CentOS-7.6.1810 - Base devrait apparaître dans la liste.

.Procédure pour les systèmes d'exploitation Rocky Linux 10, 9 ou 8
[%collapsible]
====
Utilisez cette procédure si votre système d'exploitation est *Rocky Linux 10*, *Rocky Linux 9* ou *Rocky Linux 8* pour activer l'accès aux dépôts:

.Étapes
.. Abonnez-vous aux dépôts requis :
+
[source, cli]
----
dnf config-manager --set-enabled baseos
----
+
[source, cli]
----
dnf config-manager --set-enabled appstream
----
.. Effectuez une `clean` opération :
+
[source, cli]
----
dnf clean all
----
.. Vérifiez la liste des dépôts :
+
[source, cli]
----
dnf repolist
----


....
[root@localhost ~]# dnf config-manager --set-enabled baseos
[root@localhost ~]# dnf config-manager --set-enabled appstream
[root@localhost ~]# dnf clean all
[root@localhost ~]# dnf repolist
repo id                        repo name
appstream                      Rocky Linux 10 - AppStream
baseos                         Rocky Linux 10 - BaseOS
[root@localhost ~]#
....
....
