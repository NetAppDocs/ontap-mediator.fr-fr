= Résumé du flux de travail d'installation d'ONTAP Mediator
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
L'installation d'ONTAP Mediator comprend la préparation de l'installation, la fourniture de l'accès aux référentiels, le téléchargement du package d'installation, la vérification de la signature du code et l'installation du package ONTAP Mediator.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["Un"]link:prepare-install.html["Préparez-vous à installer ONTAP Mediator"]
[role="quick-margin-para"]
Pour installer ONTAP Mediator, vous devez vous assurer que toutes les conditions préalables sont remplies.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["Deux"]link:enable-access-repos-task.html["Fournir l'accès au référentiel"]
[role="quick-margin-para"]
Vous devez autoriser l'accès aux référentiels afin qu'ONTAP Mediator puisse accéder aux packages requis pendant le processus d'installation.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["Trois"]link:download-install-pkg-task.html["Téléchargez le package d'installation d'ONTAP Mediator"]
[role="quick-margin-para"]
Téléchargez le package d'installation d'ONTAP Mediator depuis la page de téléchargement d'ONTAP Mediator.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-4.png["Quatre"]link:verify-code-signature-task.html["Vérifiez la signature du code du package d’installation d’ONTAP Mediator"]
[role="quick-margin-para"]
NetApp recommande de vérifier la signature du code de ONTAP Mediator avant d’installer le package d’installation de ONTAP Mediator.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-5.png["Cinq"]link:install-mediator-pkg-task.html["Installez le package d'installation de ONTAP Mediator"]
[role="quick-margin-para"]
Téléchargez le package d'installation et exécutez le programme d'installation sur l'hôte.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-6.png["Six"]link:verify-install-task.html["Vérifiez l'installation d'ONTAP Mediator"]
[role="quick-margin-para"]
Après avoir installé ONTAP Mediator, vérifiez qu'il fonctionne correctement.
