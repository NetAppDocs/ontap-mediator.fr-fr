= Vérifier l’état de santé de ONTAP Mediator
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vérifiez qu’ONTAP Mediator fonctionne normalement.



[[verify-the-service-status]]
== Vérifiez l'état du service

.Étapes
. Consultez l’état d’ONTAP Mediator :
+
.. Exécutez la commande suivante :
+
[source, cli]
----
systemctl status ontap_mediator
----

----

.. Consultez l'état du service SCST:
+

NOTE: Si vous avez installé ONTAP Mediator 1.12 ou une version ultérieure prenant uniquement en charge HTTPS, le package SCST n'est pas installé et vous pouvez ignorer cette tâche.

+
[source, cli]
----
systemctl status mediator-scst

[[confirm-the-listening-ports]]
== Vérifiez les ports d'écoute

. Veuillez confirmer les ports utilisés par ONTAP Mediator :
+

NOTE: Pour une installation HTTPS uniquement, seul le port 31784 sera utilisé. Les processus d’écoute sur le port 3260 dans l’exemple ci-dessous s’appliquent lorsque SCST est installé.

+
[source, cli]
----
netstat -anlt | grep -E '3260|31784'
----
+
[listing]
----
[root@scspr1905507001 ~]# netstat -anlt | grep -E '3260|31784'

         tcp   0   0 0.0.0.0:31784   0.0.0.0:*      LISTEN

         tcp   0   0 0.0.0.0:3260    0.0.0.0:*      LISTEN

         tcp6  0   0 :::3260         :::*           LISTEN
----
