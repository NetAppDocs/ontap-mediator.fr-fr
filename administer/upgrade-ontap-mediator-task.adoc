= Mettre à niveau ONTAP Mediator
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Pour mettre à niveau ONTAP Mediator vers une version plus récente sans mettre à niveau le système d'exploitation hôte, téléchargez le package d'installation de la nouvelle version et exécutez le programme d'installation sur l'hôte sur lequel ONTAP Mediator est déjà installé.


NOTE: Si vous devez mettre à niveau le système d’exploitation hôte vers une nouvelle version et réinstaller ou mettre à niveau ONTAP Mediator dans le cadre de ce processus, consultez plutôt link:upgrade-host-os-mediator-task.html["Mettez à niveau le système d'exploitation hôte et ONTAP Mediator"].

.Avant de commencer
* Vérifiez que votre hôte répond aux prérequis décrits dans link:../install/prepare-install.html["Préparez-vous à installer ONTAP Mediator"], y compris les exigences relatives à l'hôte, au pare-feu et au système d'exploitation.
* Téléchargez le package d’installation de la nouvelle version. Consultez link:../install/download-install-pkg-task.html["Téléchargez le package d'installation d'ONTAP Mediator"].
* NetApp recommande de vérifier la signature du code du nouveau package d'installation. Voir link:../install/verify-code-signature-task.html["Vérifiez la signature du code du package d’installation d’ONTAP Mediator"].


.À propos de cette tâche
Veuillez consulter les informations suivantes avant de mettre à niveau ONTAP Mediator.

* Vous devez mettre à niveau ONTAP Mediator vers la dernière version. Les versions antérieures restent compatibles avec toutes les versions d’ONTAP, mais les versions plus récentes intègrent des correctifs de sécurité pour les composants tiers.
* Lors de la mise à niveau vers une nouvelle version d'ONTAP Mediator incluant le package SCST, le programme d'installation effectue automatiquement la mise à niveau vers la version SCST recommandée, sauf si une version supérieure est disponible. Pour obtenir des instructions sur l'installation manuelle d'une version SCST supérieure, consultez link:host-maintenance-task.html["Maintenir le système d'exploitation hôte pour ONTAP Mediator"]. Pour les versions prises en charge, consultez le link:../release-notes/support-matrix.html#scst-support-matrix["Matrice de prise en charge SCST"].


[NOTE]
====
* Si la mise à niveau échoue, vous devrez peut-être essayer une version plus récente d'ONTAP Mediator.
* À compter du 15 juin 2025, vous ne pourrez plus installer ni mettre à niveau ONTAP Mediator 1.9 et 1.8, car leurs certificats de signature de code ont expiré. Si la mise à niveau échoue, utilisez plutôt la version de correctif ONTAP Mediator 1.9.1.


====
* À partir d'ONTAP 9.19.1 et ONTAP Mediator 1.12, vous avez la possibilité d'installer ONTAP Mediator avec la prise en charge d'iSCSI et d'HTTPS, ou uniquement avec la prise en charge d'HTTPS. Si vous choisissez d'installer ONTAP Mediator avec la prise en charge d'HTTPS uniquement, le package SCST n'est pas installé.
* Si vous effectuez une mise à niveau depuis ONTAP Mediator 1.11 ou une version antérieure avec SCST installé, et que vous choisissez l'option HTTPS uniquement lors de la mise à niveau, le package SCST est désinstallé et la nouvelle version d'ONTAP Mediator ne contient pas le package SCST.
* Si vous prévoyez d'utiliser ONTAP Mediator pour surveiller plusieurs configurations IP MetroCluster, la prise en charge dépend de votre type de Mediator, de la version d'ONTAP et du système d'exploitation. Consultez link:https://docs.netapp.com/us-en/ontap-metrocluster/install-ip/concept_mediator_requirements.html#mediator-multiple-mccip["Utilisez ONTAP Mediator pour surveiller plusieurs configurations IP MetroCluster"^] pour plus d'informations.
* L'installation ONTAP Mediator avec prise en charge du protocole HTTPS uniquement est prise en charge pour les cas d'utilisation suivants :
+
** Vous prévoyez d'utiliser uniquement ONTAP Mediator pour surveiller vos clusters de synchronisation active SnapMirror.
** Vous prévoyez de configurer ONTAP Mediator avec HTTPS pour surveiller une ou plusieurs configurations IP MetroCluster.


* ONTAP Mediator doit être installé avec la prise en charge d'iSCSI et de HTTPS dans le scénario suivant :
+
** Vous prévoyez de configurer ONTAP Mediator avec iSCSI pour surveiller une ou plusieurs configurations IP MetroCluster.




* Lorsque vous exécutez le programme d'installation sur une installation existante de ONTAP Mediator, il détecte la version actuelle et vous invite à confirmer la mise à niveau :
+
`ONTAP Mediator will be upgraded from version <current-version> to <new-version>.`

+
`Do you wish to continue? Y(es)/n(o):`

* Dans le cadre de la mise à niveau, le programme d'installation capture un ensemble de support de votre configuration antérieure à la mise à niveau et migre la base de données avant de mettre à niveau le logiciel ONTAP Mediator.
* Pour les cas d'utilisation d'automatisation, vous pouvez utiliser la commande  `./ontap-mediator-1.13.0/ontap-mediator-1.13.0 -y` pour ignorer les invites de l'installateur.


.Étapes
. Avant la mise à niveau, effectuez la sous-étape suivante si vous effectuez une mise à niveau vers ONTAP Mediator 1.13 ou une version ultérieure sur une instance ONTAP Mediator associée à l’une des versions suivantes :
+
** ONTAP 9.11.1 et versions antérieures
** Correctifs ONTAP antérieurs aux versions 9.12.1P15, 9.13.1P12, 9.14.1P8 et 9.15.1P2
+
... Ajoutez la ligne suivante au fichier `/opt/netapp/lib/ontap_mediator/ontap_mediator/server_config/ontap_mediator.user_config.yaml`.
+
`'generate_unique_ca_name': false`

+
Ce fichier est conservé lors des mises à niveau d’ONTAP Mediator.





. Exécutez le programme d'installation de la nouvelle version et répondez aux invites comme demandé :
+
[source, cli]
----
./ontap-mediator-1.13.0/ontap-mediator-1.13.0
----
+
[NOTE]
====
Pour ignorer la vérification de signature lors de la mise à niveau, utilisez la
`./ontap-mediator-1.13.0/ontap-mediator-1.13.0 --skip-code-signature-check` commande

====
+
