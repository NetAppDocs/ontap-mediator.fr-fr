= Régénérez un certificat temporaire auto-signé pour l’hôte ONTAP Mediator
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Régénérer un certificat auto-signé temporaire pour l'hôte actuel lorsqu'un changement de nom de l'hôte ou d'adresse IP invalide le certificat existant.


NOTE: Cette procédure n'est prise en charge que sur les systèmes exécutant ONTAP Mediator 1.7 ou une version ultérieure.

.À propos de cette tâche
* Effectuez cette tâche sur l'hôte Linux sur lequel vous avez installé ONTAP Mediator.
* Vous pouvez effectuer cette tâche uniquement si les certificats auto-signés générés sont devenus obsolètes en raison de modifications apportées au nom de l'hôte ou à l'adresse IP de l'hôte après l'installation d'ONTAP Mediator.
* Une fois le certificat auto-signé temporaire remplacé par un certificat tiers de confiance, vous ne devez _pas_ utiliser cette tâche pour régénérer un certificat. L'absence de certificat auto-signé entraînera l'échec de cette procédure.


.Étape
Pour régénérer un nouveau certificat temporaire auto-signé pour l'hôte actuel, procédez comme suit :

. Redémarrer ONTAP Mediator :
+
`./make_self_signed_certs.sh overwrite`
