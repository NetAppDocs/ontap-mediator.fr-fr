= Installez le package d'installation de ONTAP Mediator
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Pour installer ONTAP Mediator, vous devez obtenir le package d'installation et exécuter le programme d'installation sur l'hôte.


NOTE: Pour mettre à niveau une installation ONTAP Mediator existante, consultez plutôt link:../administer/upgrade-ontap-mediator-task.html["Mettre à niveau ONTAP Mediator"].

.À propos de cette tâche
* À partir d'ONTAP 9.19.1 et ONTAP Mediator 1.12, vous avez la possibilité d'installer ONTAP Mediator avec la prise en charge d'iSCSI et d'HTTPS, ou uniquement avec la prise en charge d'HTTPS. Si vous choisissez d'installer ONTAP Mediator avec la prise en charge d'HTTPS uniquement, le package SCST n'est pas installé.
* Si vous effectuez une mise à niveau depuis ONTAP Mediator 1.11 ou une version antérieure avec SCST installé, et que vous choisissez l'option HTTPS uniquement lors de la mise à niveau, le package SCST est désinstallé et la nouvelle version d'ONTAP Mediator ne contient pas le package SCST.
* Si vous prévoyez d'utiliser ONTAP Mediator pour surveiller plusieurs configurations IP MetroCluster, la prise en charge dépend de votre type de Mediator, de la version d'ONTAP et du système d'exploitation. Consultez link:https://docs.netapp.com/us-en/ontap-metrocluster/install-ip/concept_mediator_requirements.html#mediator-multiple-mccip["Utilisez ONTAP Mediator pour surveiller plusieurs configurations IP MetroCluster"^] pour plus d'informations.
* L'installation ONTAP Mediator avec prise en charge du protocole HTTPS uniquement est prise en charge pour les cas d'utilisation suivants :
+
** Vous prévoyez d'utiliser uniquement ONTAP Mediator pour surveiller vos clusters de synchronisation active SnapMirror.
** Vous prévoyez de configurer ONTAP Mediator avec HTTPS pour surveiller une ou plusieurs configurations IP MetroCluster.


* ONTAP Mediator doit être installé avec la prise en charge d'iSCSI et de HTTPS dans le scénario suivant :
+
** Vous prévoyez de configurer ONTAP Mediator avec iSCSI pour surveiller une ou plusieurs configurations IP MetroCluster.




* Lors de l'installation ou de la mise à niveau vers ONTAP Mediator 1.12 ou une version ultérieure, le programme d'installation vous invite à répondre aux éléments suivants :
+
`ONTAP Mediator can be installed with iSCSI and HTTPS support, or HTTPS support only.
Do you wish to install ONTAP Mediator with iSCSI and HTTPS support? Y(es)/n(o):`

+
** Répondez  `Yes` si vous prévoyez d'utiliser ONTAP Mediator configuré avec iSCSI pour surveiller une ou plusieurs configurations IP MetroCluster.
** Répondez  `No` si vous prévoyez d'utiliser ONTAP Mediator uniquement pour la synchronisation active SnapMirror, ou si vous prévoyez de configurer ONTAP Mediator avec HTTPS pour surveiller une ou plusieurs configurations IP MetroCluster.
+
Vous pouvez également utiliser l’ `--https-only`option dans la `./ontap-mediator-1.13.0/ontap-mediator-1.13.0`commande pour spécifier uniquement HTTPS.



* Pour les cas d'utilisation d'automatisation, vous pouvez utiliser la commande  `./ontap-mediator-1.13.0/ontap-mediator-1.13.0 -y` pour ignorer les invites de l'installateur.


.Étapes
. Exécutez le programme d'installation et répondez aux invites comme demandé :
+
[source, cli]
----
./ontap-mediator-1.13.0/ontap-mediator-1.13.0
----
+
[listing]
----
[root@mediator_host ~]# ./ontap-mediator-1.13.0/ontap-mediator-1.13.0
----
+
[NOTE]
====
Pour ignorer la vérification de signature lors de l'installation, utilisez la
`./ontap-mediator-1.13.0/ontap-mediator-1.13.0 --skip-code-signature-check` commande

====
+
Le programme d'installation crée les comptes requis et installe les packages nécessaires. Si ONTAP Mediator est déjà installé, le programme d'installation vous invite plutôt à le mettre à niveau ; pour les étapes et exemples spécifiques à la mise à niveau, consultez link:../administer/upgrade-ontap-mediator-task.html["Mettre à niveau ONTAP Mediator"].

+

NOTE: Après l'installation, la sortie système affiche les fichiers README et l'emplacement de la clé.

. Ajoutez la clé publique à la liste MOK:
+
[source, cli]
----
mokutil --import /opt/netapp/lib/ontap_mediator/ontap_mediator/SCST_mod_keys/scst_module_key.der
----
+
[NOTE]
====
Vous pouvez laisser la clé privée à son emplacement par défaut ou la déplacer vers un emplacement sécurisé. Vous devez conserver la clé publique à son emplacement actuel afin que le Boot Manager puisse l'utiliser. Pour plus d'informations, consultez le fichier README.module-signing :

`[root@hostname ~]# ls /opt/netapp/lib/ontap_mediator/ontap_mediator/SCST_mod_keys/ README.module-signing scst_module_key.der scst_module_key.priv`

====
. Redémarrez l'hôte et utilisez le gestionnaire de démarrage UEFI de votre appareil pour approuver la nouvelle clé MOK. Vous aurez besoin de la phrase secrète fournie pour l' `mokutil`utilitaire dans link:prepare-install.html#install-ontap-mediator-when-uefi-secure-boot-is-enabled["Installez ONTAP Mediator lorsque le démarrage sécurisé UEFI est activé"].




[[sign-scst-kernel-modules]]
== Signer les modules du noyau SCST

Une fois ONTAP Mediator installé, si systemctl status `mediator-scst` affiche failed (inactive), suivez ces étapes pour signer le module de noyau SCST.


NOTE: Si vous avez installé ONTAP Mediator 1.12 ou une version ultérieure prenant uniquement en charge HTTPS, le package SCST n'est pas installé et vous pouvez ignorer cette tâche.

.Étapes
. Lors du processus de compilation, une paire de clés publique/privée est générée dans le `/opt/netapp/lib/ontap_mediator/ontap_mediator/SCST_mod_keys/` répertoire. Exécutez la commande suivante pour afficher les clés générées :
+
[source, cli]
----
ls /opt/netapp/lib/ontap_mediator/ontap_mediator/SCST_mod_keys/
----
+
....
README.module-signing  scst_module_key.der  scst_module_key.priv
....
. Démarrez le processus d'importation de la clé publique dans le référentiel de clés UEFI en exécutant la commande suivante :
+
[source, cli]
----
mokutil --import /opt/netapp/lib/ontap_mediator/ontap_mediator/SCST_mod_keys/scst_module_key.der
----
+
L' `mokutil`utilitaire vous invite à saisir un mot de passe à deux reprises.

. Le logiciel mokutil demande un mot de passe temporaire pour cette clé lors du processus d'importation.
. Vérifiez si le processus d'importation a démarré à l'aide de la commande suivante, puis redémarrez le système. Le chargeur de démarrage lance le gestionnaire EFI MOK.
+
[source, cli]
----
mokutil --list-new
----
. Utilisez les menus à l'écran pour activer la clé du module noyau SCST. Après le démarrage, exécutez la commande suivante. Une fois le service lancé, les modules noyau SCST sont signés.
+
[source, cli]
----
systemctl status mediator-scst
----
