= Modifier le nom d'utilisateur et le mot de passe du médiateur ONTAP
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Modifiez le nom d'utilisateur ou le mot de passe de ONTAP Mediator depuis l'hôte Linux sur lequel ONTAP Mediator est installé.



[[change-the-username]]
== Changer le nom d'utilisateur

Vous pouvez modifier le nom d'utilisateur en suivant la procédure suivante.

.À propos de cette tâche
Effectuez cette tâche sur l'hôte Linux sur lequel vous avez installé ONTAP Mediator.

Si vous ne parvenez pas à exécuter cette commande, vous devrez peut-être l’exécuter en utilisant le chemin complet comme indiqué dans l’exemple suivant :

`/usr/local/bin/mediator_change_user`

.Étapes
Modifiez votre nom d'utilisateur en choisissant l'une des options suivantes :

* *Option (a)* : Exécutez la commande `mediator_change_user` et répondez aux invites comme indiqué dans l’exemple suivant :
+
....
 [root@mediator-host ~]# mediator_change_user
 Modify the Mediator API username by entering the following values:
     Mediator API User Name: mediatoradmin
                   Password:
 New Mediator API User Name: mediator
 The account username has been modified successfully.
 [root@mediator-host ~]#
....
* *Option (b)*: Exécutez la commande suivante:
+
`MEDIATOR_USERNAME=mediator MEDIATOR_PASSWORD=mediator2 MEDIATOR_NEW_USERNAME=mediatoradmin mediator_change_user`

+
[listing]
----
 [root@mediator-host ~]# MEDIATOR_USERNAME=mediator MEDIATOR_PASSWORD='mediator2' MEDIATOR_NEW_USERNAME=mediatoradmin mediator_change_user
 The account username has been modified successfully.
 [root@mediator-host ~]#
----




[[change-the-password]]
== Changer le mot de passe

Vous pouvez modifier le mot de passe en suivant la procédure ci-dessous.

.À propos de cette tâche
Effectuez cette tâche sur l'hôte Linux sur lequel vous avez installé ONTAP Mediator.

Si vous ne parvenez pas à exécuter cette commande, vous devrez peut-être l’exécuter en utilisant le chemin complet comme indiqué dans l’exemple suivant :

`/usr/local/bin/mediator_change_password`

.Étapes
Modifiez le mot de passe en choisissant l'une des options suivantes :

* *Option (a)* : Exécutez la `mediator_change_password` commande et répondez aux invites comme indiqué dans l’exemple suivant :
+
....
 [root@mediator-host ~]# mediator_change_password
 Change the Mediator API password by entering the following values:
    Mediator API User Name: mediatoradmin
              Old Password:
              New Password:
          Confirm Password:
 The password has been updated successfully.
 [root@mediator-host ~]#
....
* *Option (b)*: Exécutez la commande suivante:
+
`MEDIATOR_USERNAME=mediatoradmin MEDIATOR_PASSWORD=mediator1 MEDIATOR_NEW_PASSWORD=mediator2 mediator_change_password`

+
L'exemple montre que le mot de passe est modifié de « mediator1 » à « mediator2 ».

+
....
 [root@mediator-host ~]# MEDIATOR_USERNAME=mediatoradmin MEDIATOR_PASSWORD=mediator1 MEDIATOR_NEW_PASSWORD=mediator2 mediator_change_password
 The password has been updated successfully.
 [root@mediator-host ~]#
....
