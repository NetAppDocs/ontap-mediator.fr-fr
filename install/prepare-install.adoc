= Préparez-vous à installer ONTAP Mediator
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Pour installer ONTAP Mediator, vous devez remplir toutes les conditions préalables, télécharger le package d'installation et exécuter le programme d'installation sur l'hôte.

[NOTE]
====
* Pour mettre à niveau ONTAP Mediator vers une nouvelle version, consultez link:../administer/upgrade-ontap-mediator-task.html["Mettre à niveau ONTAP Mediator"].
* Si vous devez mettre à niveau le système d'exploitation hôte et réinstaller ou mettre à niveau ONTAP Mediator dans le cadre de ce processus, consultez link:../administer/upgrade-host-os-mediator-task.html["Mettez à niveau le système d'exploitation hôte et ONTAP Mediator"].


====


[[installation-requirements]]
== exigences d'installation

Veuillez prendre connaissance des exigences suivantes avant d'installer ONTAP Mediator.

[NOTE]
====
* ONTAP Mediator 1.8 et les versions antérieures ne sont pas compatibles avec le mode FIPS de Red Hat Enterprise Linux (RHEL) et empêchent son installation correcte. Vous pouvez vérifier si le mode FIPS est activé à l’aide de la commande `fips-mode-setup --check`. Vous pouvez désactiver le mode FIPS à l’aide de la commande `fips-mode-setup --disable`. Redémarrez le système après avoir désactivé le mode FIPS pour installer correctement ONTAP Mediator 1.8 ou une version antérieure.
* Si l'installation échoue, vous devrez peut-être essayer une version plus récente d'ONTAP Mediator.
* À compter du 15 juin 2025, vous ne pouvez plus installer ni mettre à niveau ONTAP Mediator 1.9 et 1.8, car leurs certificats de signature de code ont expiré. Si l'installation échoue, utilisez plutôt la version de correctif ONTAP Mediator 1.9.1.


====
* Si vous installez le `yum-utils` paquet, vous pouvez utiliser la `needs-restarting` commande.
* À partir de ONTAP Mediator 1.11, IPv6 est pris en charge pour les configurations IP MetroCluster.




[[https-and-iscsi-installation-options-for-ontap-mediator]]
[[https-iscsi-installation]]
=== Options d'installation HTTPS et iSCSI pour ONTAP Mediator

Avant d'installer ONTAP Mediator, veuillez consulter les informations suivantes :

* Dans ONTAP Mediator, le package SCST est utilisé pour fournir iSCSI pour la communication dans les configurations IP MetroCluster. Le package SCST est un module du noyau compilé lors de l'installation. À partir de ONTAP 9.19.1 et Mediator 1.12, vous pouvez configurer un ONTAP Mediator qui utilise HTTPS au lieu d'iSCSI pour surveiller une configuration IP MetroCluster.
* À partir d'ONTAP 9.19.1 et ONTAP Mediator 1.12, vous avez la possibilité d'installer ONTAP Mediator avec la prise en charge d'iSCSI et d'HTTPS, ou uniquement avec la prise en charge d'HTTPS. Si vous choisissez d'installer ONTAP Mediator avec la prise en charge d'HTTPS uniquement, le package SCST n'est pas installé.
* Si vous effectuez une mise à niveau depuis ONTAP Mediator 1.11 ou une version antérieure avec SCST installé, et que vous choisissez l'option HTTPS uniquement lors de la mise à niveau, le package SCST est désinstallé et la nouvelle version d'ONTAP Mediator ne contient pas le package SCST.
* Si vous prévoyez d'utiliser ONTAP Mediator pour surveiller plusieurs configurations IP MetroCluster, la prise en charge dépend de votre type de Mediator, de la version d'ONTAP et du système d'exploitation. Consultez link:https://docs.netapp.com/us-en/ontap-metrocluster/install-ip/concept_mediator_requirements.html#mediator-multiple-mccip["Utilisez ONTAP Mediator pour surveiller plusieurs configurations IP MetroCluster"^] pour plus d'informations.
* L'installation ONTAP Mediator avec prise en charge du protocole HTTPS uniquement est prise en charge pour les cas d'utilisation suivants :
+
** Vous prévoyez d'utiliser uniquement ONTAP Mediator pour surveiller vos clusters de synchronisation active SnapMirror.
** Vous prévoyez de configurer ONTAP Mediator avec HTTPS pour surveiller une ou plusieurs configurations IP MetroCluster.


* ONTAP Mediator doit être installé avec la prise en charge d'iSCSI et de HTTPS dans le scénario suivant :
+
** Vous prévoyez de configurer ONTAP Mediator avec iSCSI pour surveiller une ou plusieurs configurations IP MetroCluster.

[[firewall-and-networking-requirements]]
== Exigences en matière de pare-feu et de réseau

ONTAP Mediator utilise plusieurs ports pour communiquer avec des services spécifiques.

* Si vous utilisez un pare-feu tiers :
+
** L'accès HTTPS doit être activé.
** Il doit être configuré pour autoriser l'accès sur les ports 31784 et 3260.
+
Lors de l'utilisation du pare-feu par défaut de Red Hat ou CentOS, celui-ci est automatiquement configuré lors de l'installation de Mediator.



* Pour les hôtes Linux sans accès à Internet, assurez-vous que les paquets requis sont disponibles dans un dépôt local.
+
Si vous utilisez le protocole LACP (Link Aggregation Control Protocol) dans un environnement Linux, configurez le noyau et définissez le `sysctl net.ipv4.conf.all.arp_ignore` sur `2`.

[[install-ontap-mediator-when-uefi-secure-boot-is-enabled]]
== Installez ONTAP Mediator lorsque le démarrage sécurisé UEFI est activé

ONTAP Mediator peut être installé sur un système avec ou sans démarrage sécurisé UEFI activé.

.À propos de cette tâche
* Vous pouvez choisir de désactiver le démarrage sécurisé UEFI avant d’installer ONTAP Mediator si cela n’est pas nécessaire ou si vous résolvez des problèmes d’installation de ONTAP Mediator. Désactivez l’option de démarrage sécurisé UEFI dans les paramètres de votre ordinateur.
* Si vous avez installé ONTAP Mediator 1.12 ou une version ultérieure prenant uniquement en charge HTTPS, le package SCST n'est pas installé et vous pouvez ignorer cette tâche.


[NOTE]
====
Pour obtenir des instructions détaillées sur la désactivation du démarrage sécurisé UEFI, reportez-vous à la documentation de votre système d'exploitation hôte.

====
Pour installer ONTAP Mediator avec le démarrage sécurisé UEFI activé, vous devez enregistrer une clé de sécurité avant que le service puisse démarrer. La clé est générée lors de l’étape de compilation de l’installation de SCST et enregistrée sous forme de paire de clés privée/publique sur votre machine. Utilisez l’ `mokutil`utilitaire pour ajouter la clé publique en tant que Machine Owner Key (MOK) à votre micrologiciel UEFI, afin de permettre au système de faire confiance au module signé et de le charger. Enregistrez la `mokutil`phrase secrète dans un emplacement sécurisé, car elle sera nécessaire lors du redémarrage de votre système pour activer la MOK.

.Étapes
. [[step_1_uefi]]Vérifiez si le démarrage sécurisé UEFI est activé sur votre système :
+
[source, cli]
----
mokutil --sb-state
----
+
Les résultats indiquent si le démarrage sécurisé UEFI est activé sur ce système.

+

|===
+
[NOTE]
====
** Vous êtes invité à créer une phrase de passe que vous devez conserver en lieu sûr. Vous aurez besoin de cette phrase de passe pour activer la clé dans le Gestionnaire de démarrage UEFI.
** ONTAP Mediator 1.2.0 et les versions antérieures ne prennent pas en charge ce mode.


====
. [[step_2_uefi]]Si l' `mokutil`utilitaire n'est pas installé, exécutez la commande suivante :
