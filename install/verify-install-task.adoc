= Vérifiez l’état de l’installation d’ONTAP Mediator
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Après avoir installé ONTAP Mediator, vérifiez qu'il fonctionne correctement.

.Étapes
. Consultez l’état d’ONTAP Mediator :
+
[source, cli]
----
systemctl status ontap_mediator
----

Process: 286710 ExecStop=/bin/kill -s INT $MAINPID (code=exited, status=0/SUCCESS)
Main PID: 286712 (uwsgi)
Status: "uWSGI is ready"

      ├─286712 /opt/netapp/lib/ontap_mediator/pyenv/bin/uwsgi --ini /opt/netapp/lib/ontap_mediator/uwsgi/ontap_mediator.ini
      ├─286716 /opt/netapp/lib/ontap_mediator/pyenv/bin/uwsgi --ini /opt/netapp/lib/ontap_mediator/uwsgi/ontap_mediator.ini

. Consultez l’état de SCST :
+
[source, cli]
----
systemctl status mediator-scst
----
+

NOTE: Si vous avez installé ONTAP Mediator 1.12 ou une version ultérieure prenant uniquement en charge HTTPS, le package SCST n'est pas installé et vous pouvez ignorer cette étape.

+

. Veuillez confirmer les ports utilisés par ONTAP Mediator :
+
[source, cli]
----
netstat -anlt | grep -E '3260|31784'
----
+
....
         tcp   0   0 0.0.0.0:31784   0.0.0.0:*      LISTEN

         tcp   0   0 0.0.0.0:3260    0.0.0.0:*      LISTEN

         tcp6  0   0 :::3260         :::*           LISTEN
....
